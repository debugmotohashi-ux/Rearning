# 2026〜2027年 UQ・Y!mobile親子割教材更新

確認日: 2026-11-18 / アプリ版: v2.0.3

## 変更の目的

2026〜2027年の親子割を、従来の学習・テスト画面で参照できるようにする。基準は2026-10-05のUI復元後のmain（c9ecf67373984433d725746e77ae9cd79c0bbfa9）。CSS、ナビ、認証、実績の獲得条件と保存キーは維持する。

## 教材

- UQの既存2プランを更新し、対象・料金・660円割引・300GB・既存利用者の変更・終了と確認順の6カードを同じ表示形式で追加。
- 2026-11-19受付開始を明記。前年の適用歴だけで除外しない。親子割とコミコミおトク割の期間は別々に判定する。
- 既存コミコミ→翌月トクトク2→翌月コミコミの経路と期間通算を明記。11月申込→12月トクトク2適用→1月コミコミの例では、1月は親子割の2カ月目。
- 300GBは対象成人家族にも各回線で初回提供。受取期限・利用期限・消費順を明記し、利用不可になった後の残量復活と再提供がないことを区別。
- 過去コミコミおトク割適用者は、所定のゴールド割条件を満たす場合2,068円、満たさない場合2,728円。初回300GBの判定は料金と別。
- Y!mobileのS/M/Lを3,278円/4,378円/5,478円へ整合。通常カード330円＋増額220円とゴールド550円＋増額220円を分け、おうち割・家族割の条件別料金と期間終了後を掲載。
- Yの「申込・変更順序」「適用後変更・子ども回線離脱の影響」「超！おトク割との併用・優先」は確認待ちを維持。未確認の割引を最安額へ加算しない。
- UQ/Yだけ個別確認日を更新し、未確認の他教材まで新しい確認日にしない。CH7のゴールド説明はポイント還元と料金プランの割引を混同しない表現へ限定。

運用情報は教育担当者から2026-11-18に確認された内容を採用。公開情報と混同しない形で教材に記載する。300GB使用中の速度制御について追加の保証はせず、旧来の速度制限説明は追加容量のない通常時へ限定する。

## 問題・学習記録

- プラン編240問へ30問追加（UQ20問・Y10問）、合計270問。既存12問を修正。
- 通常テスト20問・クローザー30問の出題数を維持。母数表示を更新。
- 既存4問の問題文変更には、旧問題文のハッシュから新問題文のハッシュへの移行を実装。
- 復習の段階・予定日を維持。新旧の記録が同居する場合は早い予定日と低い段階を採用する。再実行は変更なし。保存失敗時にも移行済みの読み出しを保持する。
- サービス編240問は維持し、3問の解説だけを補足。既存トロフィーのリセットや追加はしない。取得済み実績は今年度教材の履修証明とはならない。
