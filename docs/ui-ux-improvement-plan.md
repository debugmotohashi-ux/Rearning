# Rearning 全画面点検・UI/UX改善計画

作成日: 2026-10-05 / 公開ベース: 0a46070f1e9e117d7e5fa08b68380459c8b7f6b6

## 目的
新人が「まず何を読むか」「今どこにいるか」「次に何をするか」を判断でき、経験者は必要な教材へすぐ移動できること。既存の教材・問題・採点・学習記録・認証を流用する。

## 点検結果
| 対象 | 問題 | 改善 |
| --- | --- | --- |
| ホーム | 初回からテストに誘導。続きからは固定ページ | 教材を読む入口を優先。実際の最終教材を記録して再開 |
| 学習一覧 | おすすめが全件表示。目的・順番が不明 | 新人の学習順と全教材検索、章・目的ごとの一覧 |
| 教材 | 円形の小さな横スクロールで項目が隠れる | 全項目が見える目次、現在地、学習の次の一歩 |
| テスト | 教材とテストの関係が不明。10〜20問の表記が不正確 | 教材への入口と20問/30問の説明、移動時の回答破棄確認 |
| 実績 | 未獲得条件が隠れている | 通常実績の名称と条件を表示。隠し実績は維持 |
| 自分 | 固定の履歴を最近の動きと表示。実績数で一人前と称する | 学習再開と記録の説明。経験・実力を推定しない |
| 共通 | 小さい文字、薄い色、曖昧な名称、押しにくい操作 | コントラスト、文字サイズ、44px以上の主要操作、名称統一、キーボード操作 |

## 実装順
1. 学習ガイドを追加。プラン・割引・通話・商材の土台・ネット基礎・回線を順に案内。閲覧を合格として扱わない。
2. ホームは推奨教材・実際の再開・教材検索の入口を優先する。
3. 教材一覧を検索可能にする。タイトルと説明から検索し、結果なしでも復帰できるようにする。
4. 教材の全目次と現在地、次の教材・確認テストを表示する。戻る時に入口を保持する。
5. 学習履歴用の新しいUI専用キーを追加。既存キー・保存値・問題ID・合格条件・認証は維持する。
6. テスト、実績、自分の表記と導線を改善。回答中に別画面へ移動する場合に確認する。
7. スマホ/iPad幅、主要全画面・教材全19項目・検索・再開・テスト回答・既存データの保持を確認し公開する。

## 判断上の注意
教材を開いたことと理解したことは異なる。閲覧の目印とテスト合格を分離する。既存教材の価格・制度の全面的な事実監査は本UI変更と区別し、確認日と公式確認への導線を残す。新人の実際の利用で迷いが減ったかは公開後のフィードバックで検証する。

## 完了条件
初回ホームから推奨教材へ1操作で到達し、すべての教材を目次から選べること。教材検索・実際の最終項目の再開・戻る・次の教材・テスト選択が動作すること。既存の進捗と学習データを変更しないこと。390/768/1194pxで横はみ出しや操作の隠れがないこと。

## 実装・検証結果
- ホーム、教材一覧、テスト一覧、実績、学習記録の全5画面を改善。教材全19項目の目次・現在地・戻るを確認。
- 新人の基本6教材の順序と次の教材への案内、実際の最終教材の再開、検索・分類・結果なし・リセットを実装。
- 見出しとボタン、補足文字のコントラスト、スマホ/iPadの配置、カード開閉のキーボード操作、実績モーダルのEscape・フォーカスを改善。
- 通常実績の未獲得条件を表示。隠し実績は維持。学習記録では教材を開いたこととテスト合格を分離。
- 390px・768px・1194pxで5画面と19項目の横はみ出しなし。料金表のみ横スクロールを維持。
- プランテストで回答、移動キャンセル・確定を確認。商材の初級20問を完走して結果表示を確認。実績モーダルを開閉確認。ページ実行エラーなし。
- 全既存インラインスクリプトを変更前とバイト比較して一致。既存教材・問題・採点・認証・復習・統計の実装は維持。更新後の再読み込みで既存保存値とログイン・再開を確認。
- JavaScript構文とgit diff --checkを確認。UIの新しい保存キーは既存データと分離。Service WorkerにUI資産を追加。
- 検証環境はChromium。iOS実機の検証、新人本人の操作評価は未実施。公開後に「最初の教材」「回線教材」「復習」を自力で開けるかを確認すると効果を評価できる。
